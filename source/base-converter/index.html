进制原理

通用公式

N = Σ di × basei
i = 0（LSB）→ n−1（MSB）

任意进制数的每一位 di 乘以基数的 i 次幂，求和即得十进制值。十进制转其他进制用「除基取余法」：不断除以基数，余数从低位到高位排列。

例：13₁₀ = 1101₂ = 1×8 + 1×4 + 0×2 + 1×1

二进制 Base-2

位权：2⁰ 2¹ 2² 2³ ...
= 1, 2, 4, 8, 16, 32 ...

只用 0 和 1，每位代表一个电路状态（通/断），是所有数字电路的基础。缺点是大数书写很长。1 位十六进制 = 4 位二进制。

1011₂ = 8+0+2+1 = 11₁₀

八进制 Base-8

位权：8⁰ 8¹ 8² ...
= 1, 8, 64, 512 ...

用 0–7，1 位八进制 = 3 位二进制。曾用于早期计算机（如 Unix 文件权限），现已基本被十六进制取代。

135₈ = 1×64 + 3×8 + 5×1 = 93₁₀

十六进制 Base-16

位权：16⁰ 16¹ 16² ...
= 1, 16, 256, 4096 ...
数字：0–9, A(10)–F(15)

用 0–9 和 A–F，1 位十六进制 = 4 位二进制，能将长二进制串压缩为易读格式。嵌入式寄存器、内存地址普遍使用。

4B6₁₆ = 4×256 + 11×16 + 6×1 = 1206₁₀
通用公式：N = Σ(dᵢ × baseⁱ)。转换方法：其他进制→十进制按位权展开；十进制→其他进制除基取余。所有计算在浏览器本地完成，数据不上传。

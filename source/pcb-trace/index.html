PCB 走线宽度计算器

IPC-2221 计算公式

A = [ I / (k · ΔTb) ]1/c
W = A / t
  1. 1截面积：A [mil²]，I [A]，ΔT [°C]
  2. 2拟合常数：b=0.44, c=0.725
  3. 3内层：k=0.024；外层：k=0.048
  4. 4走线宽度：W = A / t（t 为铜厚，mil）
  5. 5电阻：R = ρ(T)·L/A
  6. 6铜电阻率：ρ(T)=0.6787·[1+0.00393·(T−20)] µΩ·in
  7. 7压降/损耗：V=I·R，P=I²·R

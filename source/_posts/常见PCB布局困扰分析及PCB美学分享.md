原理图编译通过、确定了板形尺寸和叠层之后，PCB 设计的第一步就是**元件布局**——把每颗器件摆到合适的位置。布局不是简单的“摆积木”：布局结果的好坏直接决定了后续布线的上限，进而影响信号完整性、电源完整性、EMC、散热、可制造性乃至整块板的观感。这篇笔记结合一篇经典的布局困扰总结和洋桃电子关于“PCB 美学”的视频，把**布局原理、布局规则和美学手法**系统梳理一遍。

<!-- more -->

## 一、为什么说布局是 PCB 成功的第一步

很多新手一上来就急着连线，结果线越走越绕、过孔越打越多，最后被迫推倒重摆。正确的顺序是“**先分区、再布局、后布线**”。布局阶段要同时考虑三件事：

1. **子系统之间的内部走线关系**，尤其是时序电路、振荡电路这类敏感回路；
2. **电磁干扰的潜在路径**，系统地检查器件相对位置，让走线方便、回路尽量小；
3. **在满足电气功能的前提下尽量整齐美观**，为可制造、可调试、可维修打基础。

可以这样理解：**布线解决的是“连不连得上”，布局解决的是“连得好不好”**。布局先天不足，靠后期布线很难补救。

## 二、常见的 PCB 布局困扰

在动手前，先把这些高频疑问过一遍，能避免大量返工：

| 困扰维度 | 需要提前想清楚的问题 |
|---|---|
| 结构匹配 | 板形与整机外壳是否匹配？元件水平间距、高度方向是否冲突？ |
| 工艺与装配 | 是否需要拼版、预留工艺边？安装孔、定位孔如何排列？ |
| 电气性能 | 阻抗如何控制？信号完整性、电源稳定性如何保证？ |
| 散热 | 电源模块如何散热？发热件和热敏件距离够不够？ |
| 可维护性 | 经常更换的元件是否方便替换？可调元件是否方便调节？ |
| EMC | 怎样布局能从源头增强整板抗干扰能力？ |
| 美学 | 器件是否疏密有度、方向一致、重心平衡，像“工艺品”而不是“垃圾堆”？ |

一个成功的产品，一方面要功能质量可靠，另一方面也要布局均衡、观感专业。

## 三、布局总流程：先分区，再以核心元件为中心

### 1. 按功能模块划分区域

先按电路功能把全部元器件归到若干功能单元，使布局**顺应信号流通方向**，并尽量保持方向一致。常见模块包括：电源部分、核心控制部分、信号输入处理、信号输出处理、接插件部分、人机交互部分。

一个被广泛采用的典型摆法是：

- **电源部分集中布局在板边**（靠近电源入口，缩短输入回路）；
- **核心控制芯片放在板中央**；
- **信号输入在核心左侧、信号输出在核心右侧**，主信号从左到右单向流动；
- **接插件尽量靠板边**，方便插拔和出线；
- **人机交互部分（显示、按键）面向操作者**，符合人机工程。

![PCB 功能分区与信号流向](/images/pcb-layout/pcb-functional-partition.svg)

在保证电气性能的前提下，各模块元件应落在**栅格（Grid）**上，相互平行或垂直排列，以求整齐、美观。数字 / 模拟、高频 / 低频、高压 / 低压、强信号 / 弱信号要按模块**物理隔离**，必要时分成子板用接插件连接；高、中、低速逻辑也各占不同区域，噪声器件远离敏感器件，低电平模拟通道远离高电平通道和未滤波的电源线。

### 2. 以核心元件为中心围绕布局

分区之后，找出每个区域的关键元件（核心芯片、功率开关、电感、关键运放等），让区域内其他元件围绕它排布，做到**均匀、整体、紧凑**，尽量缩短器件间引线和连接，既方便布线又减小寄生参数和相互干扰。

### 3. 特殊元件的布局规则

特殊器件——电源器件、可调器件、发热 / 热敏器件、高频关键元件、核心芯片、易受干扰元件、大体积 / 大重量器件、高压器件和异形器件——位置要重点推敲：

- **功率回路最短化**：DC/DC 变换器、开关管、整流管尽量靠近电感 / 变压器；整流二极管尽量靠近调压元件和滤波电容，缩短大电流环路。
- **EMI 滤波器尽量靠近干扰源**，高频器件之间连线尽量短，减小分布参数；输入与输出尽量远离。
- **可调元件**（电位器、可调电感、可变电容、微动开关）结合整机结构放置，常用开关放在手容易触及处。
- **热设计**：发热元件布置在板边利于散热；若 PCB 垂直安装，发热件放在板的上方（利用热空气上升）；**热敏元件远离发热元件**。
- **电源回路面积最小**：布局要方便电源线走向，避免输入电源线“满板跑”、围出大环路；电源线与地线良好配合，否则会形成大量环路并辐射 / 耦合噪声。
- **强弱信号分道、按频率与电流开关速度分区**，避免模拟、数字、电源共用回线产生公共阻抗耦合。

## 四、两个最容易被忽视的关键布局：去耦电容与晶振

### 1. 去耦 / 旁路电容必须“紧贴电源脚”

无论模拟还是数字器件，都应在**靠近电源引脚**处放置去耦电容（最常见 0.1µF）。要求引脚尽量短、电容尽量贴近芯片，把充放电回路面积和走线感抗压到最小。

- 模拟电路中，它旁路掉电源上超出器件抑制能力的高频噪声，避免噪声进入信号路径甚至引起振荡、误响应；
- 数字电路中，它是门电路翻转瞬间的“微型电荷库”。门翻转需要很大瞬态电流，若就近没有足够电荷，电源电压会瞬间跌落，导致逻辑电平不稳、状态误翻转。

### 2. 晶振 / 谐振器“距离最近、走线最短、左右对称”

以 MCU 为主的系统里，**时序、复位、中断**是最敏感的信号，振荡器在开关瞬间尤其敏感。晶振属于射频电路，必须：尽量靠近 MCU 的 OSC 引脚、位置对称、走线等长且最短；负载电容就近接地，晶振地以最短路径回到芯片地引脚；整块晶振电路远离高电流走线，必要时用地线 / 地平面包围隔离。

## 五、换个角度看 PCB：电路、产品、美学三个维度

洋桃电子在《PCB 设计如何更美观》里提出，评价一块 PCB 可以从三个角度切入，这个框架很值得借鉴：

- **电路角度**：是否符合电路原理，是否逼近工艺极限（线宽线距、过孔、阻抗、电流承载能力）；
- **产品角度**：成本是否合理、结构与器件是否兼容、是否便于量产和装配；
- **美学角度**：布局是否有“设计感”，是否规整、有序、耐看。

美观并不是“没有实际作用的洁癖”。在人人都能画出能工作的板子的时代，**对功能之外细节的把控，正是工程能力和设计风格的外显**。更关键的是——**美学背后往往就是工程合理性**：疏密均衡对应热应力和机械应力的均衡，方向一致对应更低的焊接错误率，对齐和短路径对应更小的寄生参数。整齐，通常本身就是更好的电气布局。

## 六、PCB 美学四性与可落地手法

把“好看”拆成可执行的四条原则：**对齐、一致、有序、简洁**，并且永远是功能性优先。

### 1. 对齐（Align）

- 善用**栅格 / 格点**（如 0.05 英寸或 1mm 的整数倍），让焊盘、器件、过孔基于同一坐标系定位；
- 同类器件成行成列，中心线、边沿线对齐；安装孔围绕板中心对称分布；
- 丝印、过孔、接口同样要对齐。

### 2. 一致（Consistency）

- **方向一致**：同类型有极性元件（电解电容、二极管）极性朝向统一；IC 丝印阅读方向统一（建议整块板从左到右、从下到上可读，避免东倒西歪）；
- **间距一致**：阻容排等间距排列（可参考约 1.5 倍本体宽度的视觉节奏），避免局部过挤、局部空洞；
- 线宽、过孔、丝印字号风格、圆角规则全板统一。

### 3. 有序（Order）

- 严格功能分区，主信号沿一个方向流动，走线“少绕路”；
- 器件相对位置尽量与**原理图信号流呼应**——原理图阶段已经优化过连线长短和交叉，照着摆往往更合理；
- 相同结构的电路采用对称式标准布局（如多路相同通道镜像排布）。

### 4. 简洁（Simplicity）

- 走线短直，转角用 **45° 或圆弧**，避免锐角和不必要的绕线、交叉；
- 关键高频 / 功率回路面积越小越好；
- 丝印精简不遮挡焊盘，不堆砌冗余标注。

![PCB 布局凌乱与整齐对比](/images/pcb-layout/pcb-layout-before-after.svg)

需要强调：**好看是建立在电气性能、散热、可制造性（DFM）、可测试性（DFT）都满足之后的锦上添花**，绝不能为了对齐好看而牺牲回路面积、散热间距或安规爬电距离。此外还要兼顾元件高度尽量一致、单面贴装优先（减少工序）、先大后小先难后易的摆放顺序等工程约束。

## 七、布局完成后的自检清单

提交布线前，建议逐项打勾：

| 类别 | 检查项 |
|---|---|
| 功能分区 | 电源 / 数字 / 模拟 / 高频 / 接口是否分区隔离？主信号流向是否单向顺畅？ |
| 关键回路 | DC-DC 功率回路、输入电源回路面积是否最小？输入输出是否远离？ |
| 去耦与时钟 | 每个芯片电源脚是否就近去耦？晶振是否紧贴、对称、最短并隔离？ |
| 敏感信号 | 复位 / 中断 / 时序 / 低电平模拟是否远离高电流与噪声源？ |
| 散热 | 发热件是否靠边 / 靠上？与热敏件、电解电容是否拉开距离？ |
| 可制造 | 器件方向 / 间距是否满足贴片与波峰焊？是否预留工艺边、定位孔、安装孔？ |
| 可维护 | 易损件、可调件、测试点是否易换、易调、易测？ |
| 美学 | 是否栅格对齐、方向一致、等间距对称、疏密均衡、丝印统一可读？ |

## 八、小结

布局是 PCB 设计中“性价比最高”的环节：前期多花时间把分区、核心器件、关键回路、去耦和晶振摆对，后期布线会异常顺畅，EMC 和散热问题也会大幅减少。在此基础上，用**对齐、一致、有序、简洁**四把尺子去打磨细节，让板子既好用又好看——这正是从“能工作”走向“专业作品”的分水岭。

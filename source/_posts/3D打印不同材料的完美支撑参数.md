## 前言

在3D打印中，支撑设置是决定打印件质量的关键因素之一。支撑太难拆会损坏模型表面，支撑太松又会导致打印失败。本文综合了Bambu Lab官方文档、B站教程、抖音经验分享等多方资料，整理出针对不同材料的**完美支撑参数**，帮助你实现"支撑无痕"的打印效果。

---

## 一、支撑核心参数详解

在开始介绍具体材料之前，先了解几个关键参数：

| 参数 | 说明 | 影响 |
|------|------|------|
| **顶部Z距离** | 支撑顶端与模型悬垂面的Z轴间隙 | 越小接触越紧密但难拆，越大越好拆但可能下垂 |
| **XY距离** | 支撑与模型侧壁的水平间距 | 越大越好拆，太小会粘连 |
| **顶部接触面层数** | 支撑与模型接触的致密层层数 | 层数越多支撑面越光滑，但更难拆除 |
| **支撑密度** | 支撑柱内部填充密度 | 影响支撑强度和拆除难度 |
| **悬垂角度** | 需要支撑的最小角度 | 默认45°，越小支撑越多 |

---

## 二、PLA材料完美支撑参数

PLA是最容易打印的材料，支撑也最好处理。

### 推荐参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 支撑类型 | **树状（自动）** | 接触面小，易拆除 |
| 顶部Z距离 | **0.15-0.2mm** | 比默认稍大，方便拆除 |
| XY距离 | **0.5mm** | 留出足够拆卸空间 |
| 顶部接触面层数 | **4层** | 防止打印翻车 |
| 支撑密度 | **15-20%** | 默认即可 |
| 悬垂角度 | **45-50°** | 冷却风扇全开 |
| 支撑面图案 | **直线** | 适用于大多数情况 |

### 技巧

1. **使用树状支撑**：相比传统支撑，树状支撑与模型接触面更小，拆除时对模型损伤更低
2. **冷却风扇全开**：PLA需要充分冷却，支撑效果更好
3. **打印后2小时内拆除**：避免支撑受潮变软后难以拆除

---

## 三、PETG材料完美支撑参数

PETG粘性较大，支撑容易和模型粘连太紧，需要特别注意。

### 推荐参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 支撑类型 | **树状（自动）** | 减少接触面积 |
| 顶部Z距离 | **0.2-0.25mm** | 比PLA更大，应对粘性 |
| XY距离 | **0.6mm** | 留出更多空隙 |
| 顶部接触面层数 | **3-4层** | 平衡支撑质量 |
| 支撑密度 | **10-15%** | 降低密度，更容易拆除 |
| 悬垂角度 | **45°** | 保持默认 |
| 打印温度 | **略低于标准** | 减少材料融合 |

### 技巧

1. **降低支撑密度**：PETG本身粘性大，降低密度让支撑更"脆"，一掰就断
2. **使用树状支撑**：尽量减少接触面积
3. **打印温度微调**：温度稍低可减少材料间的融合

---

## 四、ABS/ASA材料完美支撑参数

ABS/ASA容易翘边和分层，支撑需要更稳定。

### 推荐参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 支撑类型 | **普通（自动）** | 更稳定 |
| 顶部Z距离 | **0.1-0.15mm** | 保持较小，保证支撑稳定 |
| XY距离 | **0.4mm** | 适当间距 |
| 顶部接触面层数 | **4-5层** | 增强支撑稳定性 |
| 支撑密度 | **20-25%** | 提供足够支撑力 |
| 悬垂角度 | **45°** | 保持默认 |
| 支撑筏层 | **开启** | 防止支撑底部脱落 |
| 样式 | **缺省/网格** | 官方推荐 |

### 技巧

1. **开启支撑筏层**：让支撑底部有更大附着面积，防止脱落
2. **封闭箱体**：减少温度波动，防止翘边
3. **关闭冷却风扇**：ABS需要保持高温环境
4. **冲刷量增大至800**：使用Support for ABS时，减少两种材料在喷嘴的混合

---

## 五、TPU柔性材料支撑策略

TPU是柔性材料，支撑本身也是柔性的，无法提供刚性承托，是最难处理的材料。

### 核心原则

**尽量避免给TPU加支撑！** 更好的办法是调整模型摆放角度，避免悬垂。

### 如果必须加支撑

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 支撑类型 | **树状（自动）** | 减少接触面积 |
| 顶部Z距离 | **0.25-0.3mm** | 尽可能大 |
| XY距离 | **0.8mm** | 留出足够空间 |
| 支撑密度 | **25-30%** | 提供足够支撑力 |
| 打印速度 | **降低至80%** | 给支撑更多冷却时间 |

### 技巧

1. **调整模型摆放**：这是最有效的方法，通过旋转模型避免悬垂
2. **使用AMS HT或顶部进料架**：减小进料阻力
3. **打印前充分烘干**：TPU吸湿性强，必须烘干
4. **使用0.6mm或0.8mm喷嘴**：0.4mm喷嘴进料阻力大

---

## 六、PA/PA-CF/PA6-CF工程材料支撑参数

PA类材料打印温度高，支撑和模型之间的粘接会更强。

### 推荐参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 支撑耗材 | **Support for PA/PET** | 官方专用支撑耗材 |
| 顶部Z距离 | **0.1-0.15mm** | 保持较小 |
| XY距离 | **0.4mm** | 适当间距 |
| 顶部接触面层数 | **4层** | 增强支撑质量 |
| 支撑密度 | **20-25%** | 提供足够支撑力 |
| 冲刷量 | **60-80mm³** | 减少材料混合 |

### 高温耗材支撑耗材选择

| 主体耗材 | 建议支撑耗材 | 单喷嘴设置 | 双喷嘴设置 |
|----------|--------------|------------|------------|
| PA6-GF | Bambu ABS | 仅打印支撑界面 | 支撑主体+界面 |
| PA6-CF | Bambu ASA | 仅打印支撑界面 | 支撑主体+界面 |
| PAHT-CF | Bambu ASA | 仅打印支撑界面 | 支撑主体+界面 |
| PET-CF | Bambu ASA | 仅打印支撑界面 | 支撑主体+界面 |

### 技巧

1. **使用专用支撑耗材**：Support for PA/PET与PA类材料匹配度最好
2. **2小时内拆除**：PA类材料吸水后会变软，难拆
3. **充分烘干**：打印前必须烘干耗材
4. **考虑双喷嘴**：H2D等双喷嘴机型可获得更好的支撑效果

---

## 七、PVA水溶性支撑完美参数

PVA可溶于水，适用于复杂内部支撑、机械去除型支撑难以剥离的场景。

### 推荐参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 支撑类型 | **普通支撑** | 避免树状支撑倒塌 |
| 支撑主体 | **PVA** | 主体与界面一致 |
| 支撑界面 | **PVA** | 主体与界面一致 |
| 顶部Z距离 | **0mm** | 使用PVA时可设为0 |
| 顶部接触面层数 | **3-4层** | 平衡支撑质量 |
| 冲刷量 | **30-60mm³** | 根据实际情况调整 |

### 关键要求

1. **必须使用普通支撑**：避免树状支撑（局部过于瘦高、单薄）导致倒塌
2. **主体与界面一致**：PVA需要支撑主体和界面都使用PVA
3. **极易吸潮**：烘干后无需等冷却就立刻放入干燥环境
4. **溶解水温**：PLA主体时水温不宜超过50℃，防止模型变形

---

## 八、PLA与PETG互为支撑的完美参数

PLA和PETG粘附力不强，可获得更好的支撑界面效果，支撑更容易移除。

### PLA Basic支撑PETG HF/PETG Basic

| 参数 | 设置 |
|------|------|
| 支撑主体 | **PLA Basic** |
| 支撑界面 | **PETG HF/PETG Basic** |
| PLA喷嘴温度 | 230°C |
| PETG热床温度 | 60°C（首层有PETG时） |

### PETG HF/PETG Basic支撑PLA Basic

| 参数 | 设置 |
|------|------|
| 支撑主体 | **PLA Basic** |
| 支撑界面 | **PETG HF/PETG Basic** |
| PLA喷嘴温度 | 230°C |
| PETG喷嘴温度 | 265°C（HF）/ 默认（Basic） |
| PETG热床温度 | 60°C |
| PETG最大体积速度 | 10 mm³/s |

### 技巧

1. **仅使用支撑界面材料**：推荐仅将支撑耗材作为支撑接触面，节省打印时间
2. **打开前门/顶盖**：打印过程中需要保持通风
3. **使用预设配置文件**：可从Bambu Lab Wiki下载.3mf文件直接应用

## 九、支撑类型选择指南

### 树状支撑 vs 普通支撑

| 特性 | 树状支撑 | 普通支撑 |
|------|----------|----------|
| 接触面积 | 小 | 大 |
| 拆除难度 | 容易 | 较难 |
| 支撑强度 | 中等 | 较强 |
| 适用场景 | 复杂模型、手办 | 大面积悬垂 |
| 材料消耗 | 少 | 多 |

### 树状支撑样式选择

| 样式 | 特点 | 适用场景 |
|------|------|----------|
| **苗条树** | 分支细，省材料 | 小型悬垂，精细模型 |
| **粗壮树** | 分支粗，强度高 | 大型悬垂，重载模型 |
| **混合树** | 自动选择 | 通用场景 |

## 十、常见问题解决方案

### 问题1：支撑太难拆

**解决方案：**
- 增大顶部Z距离（0.2mm → 0.25mm）
- 降低支撑密度（20% → 12%）
- 使用树状支撑减少接触面积

### 问题2：支撑面质量差

**解决方案：**
- 增加顶部接触面层数（2层 → 4层）
- 使用同心圆支撑面图案
- 使用专用支撑耗材（Support for PLA等）

### 问题3：支撑打印过程中倒塌

**解决方案：**
- 增大树状支撑分支直径
- 开启支撑筏层
- 降低打印速度

### 问题4：支撑底部从平台脱落

**解决方案：**
- 开启支撑筏层（Raft）
- 提高热床温度
- 使用胶水增加附着力

## 十一、总结

不同材料的支撑设置需要根据其物理特性进行调整：

| 材料 | 核心策略 | 顶部Z距离 | 支撑密度 |
|------|----------|-----------|----------|
| **PLA** | 树状支撑，冷却充分 | 0.15-0.2mm | 15-20% |
| **PETG** | 树状支撑，降低密度 | 0.2-0.25mm | 10-15% |
| **ABS/ASA** | 普通支撑，开启筏层 | 0.1-0.15mm | 20-25% |
| **TPU** | 尽量避免支撑 | 0.25-0.3mm | 25-30% |
| **PA/PA-CF** | 专用支撑耗材 | 0.1-0.15mm | 20-25% |
| **PVA** | 普通支撑，主体界面一致 | 0mm | 15-20% |

记住：**没有一套参数能通吃所有模型**，理解每个参数的作用和不同材料的特点，你就能根据实际情况灵活调整，告别悬垂翻车和支撑难拆的烦恼。

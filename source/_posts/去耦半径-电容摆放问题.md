"0.1µF 去耦电容，一个引脚配一个，越近越好"——这句话每个嵌入式工程师都听过。但"越近越好"到底要多近？放在 2cm 外和 5cm 外有区别吗？大电容为什么就可以随手放？这篇笔记从**安装电感**和**去耦半径**两个概念入手，把电容摆放这件事讲透，文末附一个我自己写的 Python 脚本（一键算谐振频率、波长和去耦半径）和一套用示波器就能做的 A/B 实测方案。

## 一、先纠正一个理解：电容不是电池，是中转站

很多人把去耦电容当成"给芯片供电的小电池"，这个模型会误导布局。真实的分工是：

- 芯片内部翻转时，需要在**纳秒级**抽出陡增的电流（di/dt）；
- 远处的稳压器就算再强，也要经过长长的走线和平面才能把电流送过来——路径电感会拉住它，"远水解不了近渴"；
- 去耦电容的角色是**本地电荷中转站**：快变化它先顶上，慢补充再由稳压器慢慢还给它。

既然是"就近支援"，支援速度就直接决定了去耦效果——这就引出了两个关键问题：**这条支援路径的电感有多大**（安装电感），以及**支援范围有多远**（去耦半径）。

## 二、安装电感：电容还没发挥作用就打了折

![去耦电容的本职与安装电感](/images/decoup-radius/01-decoup-principle.svg)

一颗标称"0.1nH 极低 ESL"的电容，焊到板子上后真正的电感是：

**L_总 = ESL（本体）+ L_焊盘引线 + L_过孔**

其中过孔往往是最大头。以 1nF 电容为例：理想安装（0.5nH）自谐振频率 225MHz，常规安装（两个过孔 + 短线，合计 1.6nH）直接掉到 126MHz——**安装方式让可用频段腰斩**。这就是为什么同一份 BOM，有人焊出来电源干净，有人焊出来纹波满满。

## 三、去耦半径：电容"管得着"的势力范围

![去耦半径：电容管得着的势力范围](/images/decoup-radius/02-decoup-radius.svg)

电容要补偿芯片的电流扰动，前提是"先感知到扰动、再送出补偿电流"，而这两步都受**电磁波传播速度**限制（FR4 中约 166 ps/inch）。扰动传到电容有延迟，补偿电流回到扰动区又有延迟——距离太远，补偿电流与扰动**相位对不上**，等于没帮。

以**实际工作频率**衡量这个相位关系，工程上的经验值是：**摆放距离控制在对应波长的 1/40 ~ 1/50 以内**，即：

```
r ≈ λ / 50 = v / (50 × f)      v ≈ 166 ps/inch，f = 实际工作频率
```

> **关键理解**：这个频率 f 是**电路实际工作的频率**（MCU 时钟谐波、开关电源频率等），不是电容的自谐振频率（SRF）。SRF 决定的是电容"能用到多高频率"，而去耦半径决定的是"在目标频率下要放多近"。

**算例验证**：以 100MHz 为例（MCU 常见噪声频段），波长 λ = v/f ≈ 60 英寸，去耦半径 r ≈ λ/50 ≈ 1.2 英寸 ≈ **3cm**。

不同电容在不同频率下的去耦半径：

| 电容 | 自谐振频率 SRF | 100MHz 去耦半径 | 实际工程要求 |
|---|---|---|---|
| 1nF | 125.8MHz | ≈ 2.4cm | 贴引脚（< 2cm） |
| 100nF | 12.6MHz | ≈ 3cm | 贴引脚（< 3cm） |
| 10µF | 1.13MHz | ≈ 6cm | 可稍远（< 5cm） |

> **为什么 100nF 不是 24cm？** 如果按 SRF（12.6MHz）算，半径确实约 24cm——但那是理论上限。实际 MCU 的噪声频段在 50~200MHz，在这个频段 100nF 的有效去耦半径只有 3cm 左右。所以工程上"0.1µF 贴引脚"的规则是完全正确的。

**结论**：小电容（1nF）的有效频段高、半径小，必须贴脸；大电容（10µF）的有效频段低、半径大，可稍远。但无论哪种电容，在 MCU 实际工作频率下，去耦半径都在**厘米级**——"越近越好"永远是对的。

## 四、阻抗曲线：谐振谷与反谐振峰

![阻抗曲线视角：谐振谷与反谐振峰](/images/decoup-radius/03-impedance-curve.svg)

单颗电容的阻抗是条 V 形曲线：左侧容性下降，谷点在自谐振频率 f0（深度 ≈ ESR），右侧因安装电感呈感性上翘——**一颗电容只擅长一个频段**。所以"多容值并联"是标配，但并联会引入新坑：当一颗已呈感性、另一颗仍呈容性时，相当于 L 和 C 并联，阻抗在两谷之间**反谐振飙峰**，反而比单颗更差。

对策：容值按约 10:1 梯度铺开（10µF / 1µF / 100nF / 10nF / 1nF），让峰被别的电容"压"下去；对电源质量要求高的轨，再选带受控 ESR 的端接电容或三端子穿心电容。

## 五、Python 脚本：一键复现曲线与半径

两张图和上面的表格都能用这个脚本复现（NumPy + Matplotlib），参数改成你自己的叠层与电容即可：

```python
# -*- coding: utf-8 -*-
"""decoupling.py —— 去耦电容谐振频率 / 去耦半径 / 阻抗曲线计算"""
import numpy as np

V_FR4 = 1 / 166e-12          # FR4 传播速度 ≈ 166 ps/inch（inch/s）

def srf(C, L_total):
    """计算自谐振频率 SRF"""
    return 1 / (2 * np.pi * np.sqrt(L_total * C))

def decoupling_radius_at_freq(f, v=V_FR4):
    """给定频率 f(Hz)，返回去耦半径(cm)"""
    lam = v / f               # 对应波长(inch)
    return lam / 50 * 2.54    # λ/50，转换为 cm

# ---- 1) 不同电容在 100MHz 下的去耦半径 ----
print("=" * 60)
print("实际工程算例：100MHz 工作频率下的去耦半径")
print("=" * 60)
for C, L in [(1e-9, 1.6e-9), (100e-9, 1.6e-9), (10e-6, 2.0e-9)]:
    f0 = srf(C, L)
    r_100m = decoupling_radius_at_freq(100e6)
    print(f"C={C:>7.0e}F  SRF={f0/1e6:7.1f}MHz  100MHz半径={r_100m:5.1f}cm")

# ---- 2) 100nF 在不同频率下的去耦半径 ----
print("\n100nF 电容在不同频率下的去耦半径：")
for f in [10e6, 50e6, 100e6, 200e6, 500e6]:
    r = decoupling_radius_at_freq(f)
    print(f"  f={f/1e6:6.0f}MHz → r={r:5.2f}cm")

# ---- 3) 双电容并联阻抗曲线（看反谐振峰）----
import matplotlib.pyplot as plt

f  = np.logspace(5, 9, 2000)                      # 100kHz ~ 1GHz
w  = 2 * np.pi * f
Z  = lambda C, L, R: R + 1j * (w * L - 1 / (w * C))

Z1 = Z(100e-9, 1.6e-9, 0.03)                      # 100nF + 安装电感
Z2 = Z(10e-9,  1.6e-9, 0.06)                      # 10nF + 安装电感
Zp = 1 / (1 / Z1 + 1 / Z2)                        # 并联

plt.loglog(f, abs(Z1),  label='100nF')
plt.loglog(f, abs(Z2),  label='10nF')
plt.loglog(f, abs(Zp), '--', label='parallel')
plt.axhline(0.1, color='gray', ls=':', label='target 0.1Ω')
plt.xlabel('Hz'); plt.ylabel('|Z| (Ω)')
plt.grid(True, which='both', alpha=0.3); plt.legend()
plt.show()
```

运行第一段，输出与第三节表格一致：100nF 在 100MHz 下去耦半径仅约 3cm，而非按 SRF 算出的 24cm。第二段的图上可以清楚看到两谷之间的反谐振峰——把 10nF 那路的电感改小（模拟贴脚贴孔），峰会明显降低，这就是布局优化的量化体现。

## 六、摆放实操：四种摆法的对与错

![电容摆放正误对比](/images/decoup-radius/04-decoup-placement.svg)

四个原则，按优先级排：

1. **小电容贴引脚**：先焊盘、后过孔，连接线短而粗，回路面积最小；
2. **过孔贴焊盘**：把过孔打在电容焊盘边上，而不是从焊盘再拉一段线去打孔；
3. **按半径分层**：0.1µF/1nF 贴脸（< 3cm），1µF 稍外（< 5cm），10µF 以内外围随意，频段各守各的势力范围；
4. **先看电流路径再看长度**：电源从平面来、经电容、进引脚、回地平面的整个回路都要短——只优化电容到引脚那一段是不够的。

## 七、实测：示波器就能做的 A/B 对比

理论讲完，上一套不需要网络分析仪的土办法，验证"去耦半径"是真实存在的：

| 硬件 | 规格 / 数量 | 用途 |
|---|---|---|
| 示波器 | ≥ 100MHz，探头用弹簧接地 | 测电源轨纹波（避免地线环路捡噪） |
| 信号发生器 | 方波注入 | 制造电流瞬变（或用 MCU 翻转 GPIO 代替） |
| 50Ω 注入电阻 / 同轴线 | 1 套 | 隔离注入，粗测 PDN 响应 |
| A/B 两块试验板 | 同一设计，电容摆放距离不同 | 对照组 |
| LCR 表 | — | 上板前核对实际容值 |

**方法**：A 板 0.1µF 贴引脚（距离 < 1cm），B 板同容值电容拉远 5cm（其余完全相同）；让 MCU 以 1kHz 翻转 8 路 GPIO 制造 di/dt，示波器分别抓 3.3V 轨纹波。典型的结果是 B 板纹波峰峰值明显大于 A 板——"出了去耦半径，电容形同虚设"就从理论变成了你示波器上的两条曲线。有条件的话用信号发生器经 50Ω 电阻向电源轨注入阶跃，观察电压跌落幅度，可以更定量地对比两条 PDN 的差异。

## 八、常见坑速查

| 现象 | 根因 | 处理 |
|---|---|---|
| 电容焊了纹波依旧大 | 电容超出对应频段的去耦半径（100nF 超过 3cm 就出圈） | 小容值电容移到引脚旁 |
| 高频纹波压不住 | 过孔远、走线细，安装电感大 | 过孔贴焊盘，双过孔并联降感 |
| 并联电容后某频点更糟 | 容值比不合适引发反谐振 | 容值按 ~10:1 梯度铺开 |
| 大电容"无效" | 只放了一颗大电容守全频段 | 大小电容分层配合 |
| 实测容值与标称不符 | 直流偏压效应（陶瓷电容降压掉容） | 按 DC bias 曲线选型，留足余量 |
| 探头测纹波全是天线噪声 | 探头长地线成环路 | 换弹簧接地针，短回路测量 |

## 九、小结

去耦电容设计的完整链路是：**选对容值组合 → 算准去耦半径 → 用最小安装电感焊上去 → 实测验证**。"越近越好"背后是硬核的传播延迟与相位关系——在 MCU 实际工作频率（100MHz+）下，100nF 电容的去耦半径只有约 3cm，1nF 更小到 2cm 以内。文末脚本欢迎拿去改成自己的叠层参数跑一跑。

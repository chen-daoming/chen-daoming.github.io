DC-DC 升降压电感计算器升级为 **DC-DC 综合计算器**，新增 **反馈分压电阻计算** 功能。输入参考电压和输出电压，自动遍历 E96（1%）/ E24（5%）标准电阻系列，实时生成多组可选电阻组合，并显示误差分析。

**工具地址（点击直接使用）：[https://chen-daoming.github.io/dcdc-calculator/](https://chen-daoming.github.io/dcdc-calculator/)**

## 一、新增功能：反馈分压电阻计算

### 为什么需要这个工具

几乎所有可调输出的 DC-DC 芯片（如 LM2596-ADJ、MP1584、TPS5430 等）和 LDO 都需要外部电阻分压器来设定输出电压。手工查表计算容易出错，这个工具帮你：

1. **输入 Vref 和 Vout**，自动计算理论电阻比值
2. **遍历标准电阻系列**，找出满足误差要求的所有组合
3. **按误差排序**，推荐最优组合
4. **支持 1%/5% 精度切换**，适配不同成本需求

### 支持的芯片

**DC-DC**：TPS5430/5450、LM2576-ADJ、LM2596-ADJ、MP1584、XL4001/4015、SY8088、FP6291、MC34063 等

**LDO**：TPS7A30/47/49 系列、AP2127K-ADJ、SPX3819 等

## 二、使用方法

### 基本操作

1. 输入 **参考电压 Vref**（从芯片数据手册查询）
2. 输入 **目标输出电压 Vout**
3. 选择 **电阻系列**（E96 1% / E24 5% / 混合）
4. 选择 **Vout 误差允许范围**（1% / 2% / 5%）
5. 工具自动生成多组电阻组合

## 三、计算原理

### 核心公式

```
Vout = Vref × (1 + R1/R2)
```

其中：
- **R1** = 上分压电阻（连接 Vout 到 FB）
- **R2** = 下分压电阻（连接 FB 到 GND）

### 计算步骤

1. 计算理论比值：`R1/R2 = (Vout / Vref) - 1`
2. 遍历标准电阻系列，寻找满足误差范围的 R1、R2 组合
3. 计算实际 Vout = Vref × (1 + R1/R2)
4. 验证误差 ≤ 允许值
5. 按误差从小到大排序，输出最优组合

## 四、设计注意事项

### 1. 电阻值选择范围

- **太小**（< 1kΩ）：增加静态功耗，影响效率
- **太大**（> 1MΩ）：FB 引脚漏电流影响精度，易受噪声干扰
- **推荐范围**：R2 取 1kΩ ~ 100kΩ

### 2. 精度选择

| 精度 | 电阻系列 | 适用场景 |
|---|---|---|
| 1% | E96 | 高精度电源、ADC 参考 |
| 5% | E24 | 一般供电、成本敏感 |

### 3. PCB 布局

- 分压电阻 **靠近 FB 引脚** 放置
- 远离开关节点（PH/SW）等噪声源
- 走线尽量短，减少耦合干扰

### 4. 常见问题

| 问题 | 原因 | 解决方案 |
|---|---|---|
| 输出电压偏高/偏低 | 电阻精度误差 | 选用 1% 精度电阻 |
| 输出纹波大 | FB 走线耦合噪声 | 优化布局，加滤波电容 |
| 负载调整率差 | 分压电阻值太大 | 减小电阻值 |

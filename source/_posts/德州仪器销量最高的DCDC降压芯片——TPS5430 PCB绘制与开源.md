TPS5430 是德州仪器（TI）推出的宽输入电压范围、3A 输出电流的非同步 Buck 降压芯片，凭借 **5.5V–36V 宽输入、500kHz 固定开关频率、内部补偿** 等特点，成为工业控制、汽车电子、通信设备等领域出货量最大的 DC-DC 降压方案之一。本文基于 TI 官方数据手册和实际绘制经验，系统梳理 TPS5430 的芯片参数、电路设计要点、PCB layout 注意事项，并提供开源原理图与 PCB 文件。

## 一、芯片核心参数速查

| 参数 | 数值 | 说明 |
|---|---|---|
| 输入电压范围 | 5.5V – 36V | TPS5430 版本，TPS5431 为 5.5V–23V |
| 输出电压范围 | 1.22V – 31V | 可调，最低由内部 1.221V 参考电压决定 |
| 最大输出电流 | 3A 连续 / 4A 峰值 | 非同步整流，续流二极管需外部配置 |
| 开关频率 | 500kHz 固定 | 不可调，利于缩小滤波元件体积 |
| 高侧 MOSFET 导通电阻 | 100mΩ（典型值） | VIN=12V 时，VIN=5.5V 时约 125mΩ |
| 最大占空比 | 87% – 89% | 限制了最高输出电压（Vin × 0.87） |
| 参考电压 | 1.221V ±1.5% | 25°C 典型值，全温度范围 ±2% |
| 效率 | 最高 95% | 取决于输入输出电压差和负载电流 |
| 静态电流 | 2mA（非开关） | 关断时仅 15µA |
| UVLO 阈值 | 5.3V（上升）/ 5.0V（下降） | 迟滞 0.35V |
| 过流保护 | 4A – 6A | 逐周期限流 + 打嗝模式恢复 |
| 过压保护 | 112.5% Vout | 输出过压时关断高侧 MOSFET |
| 热关断 | 162°C（上升） | 迟滞 14°C |
| 工作温度 | -40°C – 125°C | 结温范围 |
| 封装 | HSOP-8（DDA） | 带 PowerPAD 散热焊盘 |

### 引脚功能

| 引脚 | 名称 | 功能 |
|---|---|---|
| 1 | BOOT | 自举电容连接，为高侧 MOSFET 栅极驱动供电 |
| 2, 3 | NC | 内部未连接 |
| 4 | VSENSE | 输出电压反馈，连接电阻分压器 |
| 5 | ENA | 使能控制，>1.3V 开启，<0.5V 关断，可悬空 |
| 6 | GND | 地，必须连接到 DAP 散热焊盘 |
| 7 | VIN | 输入电源，需就近放置去耦电容 |
| 8 | PH | 开关节点，连接电感和续流二极管 |
| DAP | GND | 散热焊盘，必须焊接到 PCB 地平面 |

## 二、典型应用电路设计

### 1. 设计需求示例

以最常见的 **12V 输入 → 5V 输出 / 3A** 为例：

| 参数 | 值 |
|---|---|
| 输入电压范围 | 10.8V – 19.8V（12V ±20%） |
| 输出电压 | 5V |
| 输出电流 | 3A |
| 输入纹波 | ≤300mV |
| 输出纹波 | ≤30mV |
| 开关频率 | 500kHz |

### 2. 输出电压设定

输出电压由 VSENSE 引脚的电阻分压器决定：

```
Vout = Vref × (1 + R1/R2)
Vref = 1.221V
```

常用配置：

| 输出电压 | R1 | R2 |
|---|---|---|
| 3.3V | 10kΩ | 5.76kΩ |
| 5V | 10kΩ | 3.24kΩ |
| 12V | 39.2kΩ | 3.92kΩ |
| -5V（反相） | 见反相拓扑章节 | — |

### 3. 输出电感选型

电感量计算公式：

```
L = Vout × (1 - D) / (ΔIL × fsw)
D = Vout / Vin
ΔIL = r × Iout（纹波率 r 取 0.2~0.4）
```

**12V→5V/3A 示例**：
- D = 5/12 ≈ 0.417
- 取 r = 0.3，ΔIL = 0.9A
- L = 5 × (1-0.417) / (0.9 × 500k) ≈ 6.5µH
- **推荐标称值：6.8µH 或 10µH**

电感选型要点：
- **饱和电流 Isat ≥ 1.3 × Ipeak**，Ipeak = Iout + ΔIL/2
- 直流电阻 DCR 尽量小，减少导通损耗
- 频率 500kHz 下，铁氧体磁芯电感即可满足要求
- 封装尺寸考虑 PCB 空间和散热

### 4. 输出电容选型

输出电容影响输出纹波和瞬态响应：

- **推荐使用铝电解电容 + 陶瓷电容组合**
- 铝电解：100µF – 470µF，提供体电容和储能
- 陶瓷：10µF – 22µF（X5R/X7R），降低高频纹波
- ESR 是影响纹波的关键因素，低 ESR 电容纹波更小

**纹波电压估算**：

```
ΔVout ≈ ΔIL × ESR + ΔIL / (8 × Cout × fsw)
```

### 5. 续流二极管选型

TPS5430 是非同步 Buck，需要外部续流二极管：

- **推荐肖特基二极管**：正向压降低、反向恢复快
- 额定电流 ≥ 1.5 × Iout（留余量）
- 反向耐压 ≥ 最大输入电压
- 常用型号：**SS34**（3A/40V）、**SS54**（5A/40V）、**MBR340**（3A/40V）

### 6. 输入电容选型

- **最低 4.7µF 陶瓷电容**（X5R/X7R），推荐 10µF
- 耐压 ≥ 最大输入电压 + 纹波
- 大电流应用可并联电解电容（100µF）提供体电容
- **必须就近放置**，距离 VIN 引脚 ≤ 1mm

### 7. 自举电容

- 连接在 BOOT 和 PH 引脚之间
- 推荐 **0.01µF – 0.1µF** 低 ESR 陶瓷电容
- 耐压 ≥ 10V
- 靠近 IC 放置，走线尽量短

## 三、PCB Layout 注意事项

PCB 布局是开关电源设计成败的关键。以下是基于 TI 官方指南和实际经验的要点：

### 1. 功率回路最小化

**这是最核心的原则。** 开关电源的 EMI 和纹波主要来自大电流、高 dV/dt 的环路。

需要最小化的关键环路：

| 环路 | 路径 | 重要性 |
|---|---|---|
| 输入去耦环路 | VIN 电容 → VIN 引脚 → GND | ★★★★★ |
| 续流环路 | PH → 二极管 → GND → 输入电容 | ★★★★★ |
| 输出滤波环路 | PH → 电感 → 输出电容 → GND | ★★★★☆ |
| BOOT 环路 | BOOT 电容 → BOOT/PH 引脚 | ★★★☆☆ |

### 2. 元件放置优先级

```
第一优先：输入去耦电容（C1）
第二优先：续流二极管（D1）
第三优先：输出电感（L1）
第四优先：输出电容（C2）
第五优先：BOOT 电容、反馈电阻
```

### 3. VIN 走线

- 输入去耦电容 **C1 必须紧贴 VIN 引脚**，距离 ≤ 1mm
- VIN 走线要短、宽，承载大电流
- 在 VIN 走线旁铺设大面积地铜皮

### 4. PH（开关节点）走线

- PH 是最敏感的节点：**高 dV/dt、大电流**
- 走线面积尽量小，避免成为 EMI 天线
- 电感紧贴 PH 引脚放置
- 续流二极管也靠近 PH 引脚
- **不要在 PH 走线下方走敏感信号线**

### 5. GND 设计

- IC 正下方必须有 **裸露地铜皮**，连接 DAP 焊盘
- 通过多个过孔连接内层地平面
- 输入/输出电容的地端也用过孔就近连接地平面
- **地平面要完整**，不要被信号线割断

### 6. VSENSE 反馈走线

- 反馈电阻分压器靠近 VSENSE 引脚放置
- VSENSE 走线 **远离 PH 走线**，避免耦合噪声
- 可以从输出电容之后（干净的 Vout）取反馈点
- 如果空间允许，走线可以经过输出电容下方或换层

### 7. 散热设计

- DAP 焊盘 **必须焊接到 PCB**，是主要散热路径
- IC 正下方放置 4 个以上的过孔，连接内层地平面散热
- 铜皮面积越大散热越好
- 大电流应用考虑使用 2oz 铜厚

### 8. 层叠建议

| 层 | 内容 |
|---|---|
| Top | 主功率走线、所有元件 |
| Inner 1 | 完整地平面 |
| Inner 2 | 电源/信号走线 |
| Bottom | 辅助走线、散热铜皮 |

### 9. 常见 Layout 错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| VIN 电容远离 IC | 输入纹波大、EMI 超标 | 紧贴 VIN/GND 引脚 |
| PH 走线面积大 | 辐射 EMI 严重 | 缩短走线，减小面积 |
| 地平面被割断 | 回流路径长、噪声大 | 保持地平面完整 |
| 反馈线靠近 PH | 输出电压抖动 | 远离开关节点 |
| DAP 未良好焊接 | 过热、效率下降 | 确保焊接良好，多过孔散热 |

## 四、产生负电压的反相拓扑

TPS5430 还可以配置为 **反相 Buck-Boost** 拓扑，产生负电压输出：

- 将 GND 引脚接到正输出
- 原 VIN 接系统地
- 原 GND 输出负电压

典型应用：**+12V → -5V**，用于运放供电、LCD 偏置等。

注意事项：
- 输出电流能力下降（约 2.25A）
- 二极管和电感选型需要重新计算
- PCB 布局参考 TI 应用手册 SLVA114

## 五、纹波与噪声抑制技巧

### 1. 输出纹波优化

- 增大输出电容容量
- 选择低 ESR 电容（固态电容、陶瓷电容）
- 电感值适当增大（减小纹波电流）

### 2. 开关噪声抑制

- 在输出端增加 **LC 滤波**（小电感 + 陶瓷电容）
- 在 VIN 端并联 0.1µF 陶瓷电容滤除高频噪声
- 使用铁氧体磁珠串联在输出端

### 3. PCB 层面

- 输入/输出电容的地过孔要多、要近
- 开关节点走线面积最小化
- 敏感信号远离功率回路

- **更高电流**：TPS5450（5A）或多相方案

## 八、设计 Checklist

在投板前，对照以下清单逐项检查：

- [ ] 输入电容紧贴 VIN/GND 引脚（≤1mm）
- [ ] 续流二极管靠近 PH 引脚
- [ ] 电感靠近 PH 引脚，走线面积小
- [ ] 输出电容紧贴电感输出端
- [ ] BOOT 电容靠近 BOOT/PH 引脚
- [ ] 反馈电阻靠近 VSENSE 引脚
- [ ] VSENSE 走线远离 PH 走线
- [ ] DAP 焊盘有足够过孔（≥4 个）连接地平面
- [ ] 地平面完整，未被信号线割断
- [ ] 大电流走线宽度足够（≥0.5mm/A）
- [ ] 输入/输出连接器走线加宽

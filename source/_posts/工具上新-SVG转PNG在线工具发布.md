## 新工具上线：SVG 转 PNG

今天为大家带来一个实用的新工具 —— **SVG 转 PNG 在线转换工具**，已上线至博客工具栏。

### 功能特点

- **纯本地处理**：所有转换在浏览器内完成，文件不上传服务器
- **多种尺寸模式**：
  - 保持原尺寸
  - 缩放比例（1x/2x/3x/4x）
  - 自定义宽高
- **实时预览**：调整参数即时查看效果
- **一键下载**：文件名自动包含尺寸信息

### 使用场景

1. **技术博客配图**：将 SVG 架构图转换为 PNG 供博客使用
2. **社交媒体分享**：生成适合各平台尺寸的图片
3. **文档嵌入**：Office 文档、PDF 中嵌入高清图片
4. **UI 设计素材**：导出图标、插图等设计素材

### 访问方式

博客顶部导航栏 → 工具栏 → SVG 转 PNG


### 技术实现

- 基于 HTML5 Canvas API
- 纯前端实现，无需后端
- 响应式设计，支持移动端

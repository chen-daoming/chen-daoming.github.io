板子第一次过静电测试就重启、RS485 常年莫名挂掉、12V 输入一插浪涌就烧后级——这类事故十有八九都能追溯到同一件事：**防护管没选对，或者选对了却没放对**。TVS 管和 ESD 管长得几乎一样（都是反向并联的二极管），数据手册参数却各说各话，新手最容易在这里翻车。这篇笔记把两者的技术指标掰开讲清，给一条可落地的五步选型流程，并附上我自己的实测台架和配套代码，供直接抄作业。

## 一、先分清：TVS 管和 ESD 管到底差在哪

两者原理相同——都是利用雪崩击穿钳位电压：平时呈现高阻几乎不参与工作，浪涌来袭瞬间反向导通，把电流泄放到地、把电压钳在安全水平。区别在于"量级"和"岗位"：

| 维度 | ESD 保护管 | TVS 管 |
|---|---|---|
| 岗位 | 板级接口第一线（USB/按键/天线/总线） | 电源入口、功率线、户外接口 |
| 峰值脉冲功率 | 50W ~ 500W 量级 | 400W ~ 6.5kW 量级 |
| 结电容 C_J | 0.3 ~ 3 pF（高速口专用） | 数十 pF ~ 数十 nF（电源线无所谓） |
| 响应速度 | < 1 ns（雪崩机制本身 ps 级） | < 1 ns |
| 考核标准 | IEC 61000-4-2（接触 ±4/6/8kV，空气 ±8/15kV） | IEC 61000-4-5（1.2/50µs + 8/20µs 组合波） |
| 典型封装 | DFN-2/4、0402、SOT-23（省板面积） | SMA/SMB/SMC、DO-15/DO-41（吃功率） |

**一句话分工：ESD 管"快而省"，守接口；TVS 管"壮而狠"，守电源。** 拿 ESD 管扛浪涌会直接炸管，拿大功率 TVS 管护 USB 差分对，几百度法的结电容会把边沿拖到没法看——两个方向的反例我都见过。

![板级防护体系：ESD 管（前级）与 TVS 管（后级）的分工](/images/tvs-esd/01-tvs-esd-position.svg)

位置上还有一条铁律：**管子越靠入口越好，泄放回路越短越好**。防护管的电流路径是"连接器 → 管子 → 地"，这条回路每多 1cm，寄生电感就多约 1nH——浪涌电流 20A 时，仅电感就额外贡献 20V 以上的电压抬升，钳位效果直接打折。

## 二、I-V 特性与关键参数逐个讲

![TVS / ESD 管的 I-V 特性与关键参数](/images/tvs-esd/02-tvs-iv-curve.svg)

防护管是反着接的，关注的是第三象限的反向击穿特性，参数一共六个：

**1. V_RWM（最高工作电压）——"平时必须装死"**
线路最高工作电压必须低于 V_RWM，否则常态漏电流偏大、发热，甚至临近击穿。工程惯例：V_RWM ≥ 线路电压 × 1.1~1.2。12V 电源轨选 13V 档而不是 12V 档，5V 轨选 5.5~6V 档，就是留这个裕量。

**2. I_R（反向漏电流）——"装死要装得干净"**
V_RWM 下的漏电流，通常 µA 级。电池供电产品要重点看这个参数，漏电流大的防护管会悄悄吃掉待机电流。

**3. V_BR（击穿电压）——"该动就动"**
@1mA 测试点的雪崩击穿电压，一般落在 (1.2~1.5)×V_RWM 之间，手册给 ±5% 或 ±10% 公差。V_BR 必须高于线路正常工作的所有瞬态（包括电源纹波尖峰），否则"没浪涌也动作"。

**4. V_C（钳位电压）——"浪涌时压得住"**
@I_PP 大电流下的残压，是真正决定后级死活的数据。选型判据：**V_C ≤ 后级芯片的绝对最大额定值**。注意 V_C 随 I_PP 线性走高——同一个管子，小电流下 V_C 漂亮，大电流下可能翻倍，所以必须"成对"看。

**5. I_PP（峰值脉冲电流）与 P_PP（峰值脉冲功率）**
P_PP = V_C × I_PP，按 10/1000µs 或 8/20µs 等标准波形标定。**换波形不换功率**：同一根管子标 600W（10/1000µs），在 8/20µs 波形下能扛的峰值电流完全不同。选型时先明确要防的波形（IEC 61000-4-5 等级），再对号入座，并留 30% 以上裕量。

**6. C_J（结电容）——"高速口的生死线"**
USB 2.0 差分对 90Ω 阻抗、边沿 ns 级，挂一颗几十 pF 的管子等于每根线并了颗大电容，眼图直接糊掉。经验值：USB 2.0 / SPI 高速线选 C_J ≤ 1pF，CAN/485 选 10~30pF 无压力，电源线则完全不用管它。

## 三、五步选型流程 + 实例走一遍

![TVS / ESD 管五步选型流程](/images/tvs-esd/03-tvs-selection-flow.svg)

**实例：给一个 12V 电源输入口防浪涌（IEC 61000-4-5，2kV 组合波）**

1. **明确场景**：直流电源输入，单向，浪涌为主 → 选单向 TVS；
2. **定 V_RWM**：≥ 12V × 1.1 ≈ 13.2V → 看中 SMBJ13A（V_RWM = 13V）；
3. **算能量**：2kV 组合波在低阻抗源下的短路电流约 133A，经源阻抗和前级限流后按 20~30A 估算 → 查手册 SMBJ13A 的 I_PP ≈ 28A（P_PP = 600W），刚好覆盖，若浪涌等级更高则上 SMCJ 或并联；
4. **查 V_C**：V_C ≈ 21.5V @ 28A → 后级如果直接是 12V 转 5V 的 DCDC（耐压 30V+），没问题；若是裸 MCU 引脚则不可接受，需要前移或分级；
5. **定封装布局**：SMB 贴板，放在电源入口连接器正后方，地回路就近打过孔。

ESD 侧同理：USB 2.0 口选 V_RWM = 5V、C_J ≤ 1pF 的低容阵列（如 USBLC6 类器件，±15kV 气隙/接触 ±8kV），贴着连接器放。

## 四、实测验证：别只信手册曲线

![配套实测：钳位波形台架与受保护输入电路](/images/tvs-esd/04-tvs-test-bench.svg)

手册的 V_C 是标称波形下的值，自己板子上的残压才是真的。我的摸底台架：

| 硬件 | 规格 / 数量 | 用途 |
|---|---|---|
| 示波器 | ≥ 100MHz，10:1 高压探头 | 抓钳位平台与过冲 |
| 信号发生器 + 功率放大器 | 输出近似 1.2/50µs 浪涌脉冲 | 模拟浪涌源（正式认证需组合波发生器） |
| ESD 摸底 | 静电放电笔 / 打火装置近似 | 接口静电初筛 |
| DUT 试验板 | 预留 TVS 焊位，可切换有/无 | A/B 对比钳位效果 |
| 万用表 / LCR 表 | — | 上电前核对 V_BR 档位与焊接 |

**方法**：同一注入条件下先拍"无 TVS"的过冲波形，再拍"有 TVS"的钳位平台，两个峰峰值一对比，钳位效果一目了然；验收线是 V_C 平台低于后级芯片的绝对最大额定值。这套台架做工程摸底足够，正式认证仍需送专门实验室。

## 五、配套代码：硬件防护之后的软件第二道保险

防护是系统工程，TVS 负责钳压，软件还要负责"别被残余毛刺骗到"。以图 4 的受保护输入为例（ESD 管 → 限流电阻 → RC → MCU 引脚），我在软件里再做一层中值滤波，剔除钳位瞬间的残留尖峰：

```c
/* adc_filter.c —— 5 次采样取中值：剔除 TVS 钳位瞬间的残留毛刺 */
#include "adc.h"

uint16_t ADC_ReadMedian(ADC_HandleTypeDef *hadc, uint32_t ch)
{
    uint16_t buf[5];
    ADC_ChannelConfTypeDef cfg = {0};

    cfg.Channel      = ch;
    cfg.Rank         = ADC_REGULAR_RANK_1;
    cfg.SamplingTime = ADC_SAMPLETIME_55CYCLES_5;   /* 采样时间长一点，让钳位尖峰过去 */
    HAL_ADC_ConfigChannel(hadc, &cfg);

    for (uint8_t i = 0; i < 5; i++) {
        HAL_ADC_Start(hadc);
        HAL_ADC_PollForConversion(hadc, 2);
        buf[i] = (uint16_t)HAL_ADC_GetValue(hadc);
        HAL_ADC_Stop(hadc);
    }

    /* 插入排序后取中值：最多剔除 2 个离谱采样点 */
    for (uint8_t i = 1; i < 5; i++) {
        uint16_t key = buf[i];
        int8_t   j   = i - 1;
        while (j >= 0 && buf[j] > key) { buf[j + 1] = buf[j]; j--; }
        buf[j + 1] = key;
    }
    return buf[2];
}
```

```c
/* main.c：受保护引脚的使用方式 */
uint16_t raw = ADC_ReadMedian(&hadc1, ADC_CHANNEL_0);   /* 经 TVS + RC 的输入 */
if (raw > ADC_FAULT_THRESHOLD) {                         /* 软件再判一层异常 */
    fault_flag |= FAULT_INPUT_OVER;
}
```

硬件钳位 + 限流 + 滤波 + 软件中值，四层防线各司其职，哪层都不能省。

## 六、常见坑速查

| 现象 | 根因 | 处理 |
|---|---|---|
| 上电管子发烫、电源纹波变大 | V_RWM 贴着电源电压选 | 按 1.1~1.2 倍抬档 |
| 管子炸裂开路 | 用 ESD 管扛浪涌、P_PP 无裕量 | 按波形等级换 TVS 并留 30% 裕量 |
| 高速信号眼图闭合 | 结电容过大 | 换 C_J ≤ 1pF 的 ESD 专用管 |
| 加了 TVS 还是烧后级 | 管子离接口远、地回路绕 | 管子贴连接器，泄放路径打过孔 |
| 双向信号负半周被钳死 | 单向管用在交流信号上 | 交流/双向信号选双向管 |
| 485 总线雷雨天批量损坏 | 只防了差模没防共模，或没共模扼流圈 | 差模 TVS + 共模电感 + GDT 分级 |

## 七、小结

TVS 管和 ESD 管的选型，说复杂也复杂（六个参数、两种波形标准），说简单也简单——记住三句话：**V_RWM 卡"平时不误动"，V_C/I_PP 卡"浪涌时压得住"，C_J 卡"别拖累信号"**；然后把管子贴在入口上，把地回路做到最短。剩下的，交给示波器验证。

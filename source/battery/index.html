电池续航计算器

根据电池容量和负载电流/功率估算续航时间，支持 Ah/mAh/Wh 容量输入、A/mA/W 负载输入，附效率修正与常见电池参考表。

参数输入

Wh 模式需填写电池标称电压
W 模式通过电压转换为电流
考虑老化、温度、升压损耗，默认 85%

电池放电示意

计算公式

T = C / I × η
  1. 1容量统一：Ah = mAh / 1000
  2. 2瓦时转换：Ah = Wh / V
  3. 3电流统一：A = mA / 1000 = W / V
  4. 4理论续航：T_ideal = Ah / A（小时）
  5. 5实际续航：T = T_ideal × η
η 为放电效率系数（0–100%），涵盖电池老化、温度衰减、DC-DC 升压/降压损耗、自放电等。低功耗场景（µA 级）需额外考虑自放电，此时估算偏差较大。

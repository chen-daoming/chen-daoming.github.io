计算公式

R = (Vs − N×Vf) / If
P = (Vs − N×Vf) × If
  1. 1LED 总压降：Vf_total = N × Vf
  2. 2电阻压降：Vr = Vs − Vf_total
  3. 3限流电阻：R = Vr / If
  4. 4电阻功耗：P = Vr × If = Vr² / R
  5. 5额定功率：P_rated ≥ P × 2（建议 2–10 倍）
必须满足 Vs > N × Vf，否则 LED 无法正常点亮。
